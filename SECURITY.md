# Sécurité

## Signaler une vulnérabilité

Merci de ne pas ouvrir d'issue publique pour une faille de sécurité.

Écrivez à [bonjour@sylvain.dev](mailto:bonjour@sylvain.dev), avec « Sécurité » dans l'objet.

Décrivez la page ou le fichier concerné, comment reproduire le problème et son impact. Je réponds sous 7 jours et je vous tiens informé jusqu'à la correction. Si vous le souhaitez, vous serez remercié dans le correctif.

## Périmètre

- le site [www.sylvain.dev](https://www.sylvain.dev) (et la redirection de `sylvain.dev`) ;
- le code de ce dépôt : gabarits Eleventy, scripts, workflows GitHub Actions, configuration de Sveltia CMS (`/admin`).

Hors périmètre : les services tiers (Cloudflare, GitHub, webmention.io), les rapports automatiques sans démonstration d'impact, et les en-têtes ou réglages déjà notés A+ par [Mozilla Observatory](https://developer.mozilla.org/en-US/observatory/analyze?host=www.sylvain.dev) sauf contournement avéré.

## Versions prises en charge

Seule la version en ligne, construite depuis la branche `main`, est maintenue.
